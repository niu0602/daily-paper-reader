## 摘要
使用头戴式双目相机的长时程类人视觉—语言—动作（VLA）控制需要一种既能利用互补视角、又能与预训练表示保持兼容的视觉接口。现有接口常常丢弃互补的双目证据，或在未保留原生主视角路径、且未将辅助信息适配于机器人具身性的情况下融合额外观测。我们提出 EATR-Stereo，这是一种具身性感知的 token 路由框架，通过查询同步的辅助视角 token 序列，保留主视角 token 并构建与主视角对齐的跨视角辅助 token（CVAT）。一个按身体分段的本体感觉编码器进一步依据机器人的构型历史，对逐 token 的辅助使用进行条件化，从而在动作生成过程中选择性地纳入双目证据。经路由的辅助流在保持其视觉—语言模型冻结的同时，增强预训练 VLA 的语言与主视觉上下文。在一台具有 33 自由度、37 维本体感觉状态的实体类人机器人上，我们在耗时超过 100 秒的搜索—接近—抓取—放置—返回任务中评估了九种配置。EATR-Stereo 实现了 60.0% 的整任务成功率、100.0% 的抓取成功率和 80.0% 的阶段成功率。在严重的非对称遮挡条件下，与仅使用 CVAT 相比，其恢复率提升至 80%，而后者仅为 30%。消融研究进一步表明，保留主视角 token，并将跨视角辅助特征与结构化

## Abstract
Long-horizon humanoid vision--language--action (VLA) control with head-mounted stereo cameras requires visual interfaces that can exploit complementary views while maintaining compatibility with pretrained representations. Existing interfaces often discard complementary stereo evidence or fuse additional observations without preserving the native primary-view pathway and adapting auxiliary information to robot embodiment. We present EATR-Stereo, an embodiment-aware token-routing framework that retains primary-view tokens and constructs primary-aligned Cross-View Auxiliary Tokens (CVATs) by querying the synchronized auxiliary-view token sequence. A body-segmented proprioceptive encoder further conditions token-wise auxiliary usage on robot configuration history, enabling selective incorporation of stereo evidence during action generation. The routed auxiliary stream augments the language and primary-visual context of a pretrained VLA while keeping its vision--language model frozen. On a 33-DoF physical humanoid with a 37-D proprioceptive state, we evaluate nine configurations in over-100-s search--approach--grasp--place--return tasks. EATR-Stereo achieves 60.0% full-task success, 100.0% grasp success, and 80.0% stage success. Under severe asymmetric occlusion, it improves recovery to 80% compared with 30% for CVAT alone. Ablation studies further show the importance of preserving primary tokens and combining cross-view auxiliary features with structured proprioceptive routing. These results demonstrate that selectively routed paired stereo evidence improves spatial grounding for reliable long-horizon humanoid VLA control.

## 1. 核心问题与整体含义（研究动机与背景）
- 问题背景：
  - 类人机器人在长时程任务中，头戴式双目摄像机的视角随身体运动变化，导致视觉感知与全身运动强耦合；步态与躯干扰动、头腰转动、手臂自遮挡等使得单视图常出现证据缺失与时序不一致。
  - 同步立体（paired stereo）相机具备固定/可标定基线、同一时间戳、跨视角对应和视差，同时在一视图遮挡时提供互补可视性；因此有别于任意多视图，其“有效信号”在于视对关系而非仅增加图像数。
- 现有缺陷：
  - 许多 VLA 接口要么丢弃互补立体证据，要么直接拼接多视图而不显式关联跨视角空间一致性；或用深度/3D显式表征但不适配头戴双目、步态扰动场景，且往往替换预训练的单目主视 token 结构。
  - 视觉-本体感觉融合多关注表征对齐与鲁棒性，缺乏依据具身语义状态选择跨视角证据的机制。
- 研究目标与整体含义：
  - 在不改动/微调预训练 VLM 的前提下，提出一种轻量接口，将同步双目互补证据以“主视保留、跨视对齐、具身路由”的方式注入到已有 VLA，提升长时程类人控制的空间落地与稳健性。

## 2. 方法论（核心思想、关键技术细节、算法流程）
- 核心思想：
  - 保留主视图的原生语义 token 流，采用跨视角注意力从辅视序列构建“主视对齐”的辅助 token（CVAT），并利用“按身体分段”的本体感觉历史对每个辅助 token 进行门控路由，选择性整合互补双目证据。
- 关键模块与流程：
  - 输入与任务形式化：
    - 在时刻 t，观测包含同步双目图像 (I_L^t, I_R^t)、指令 l_t、以及最近 K 帧的本体感觉历史 S_t。策略预测 H 步连续动作块（chunk）。
    - 固定指定一视图为主视 I_p^t，另一为辅视 I_a^t。
  - 冻结的 VLM 编码与序列拆分：
    - 使用预训练 Cosmos VLM（冻结）联合编码图像与语言，得到语言序列 L_t、主视视觉序列 M_t、辅视视觉序列 A_t（加入视角角色嵌入）。
  - CVAT 构建（跨视角注意力，主视为 Query，辅视为 Key/Value）：
    - 对每个主视 token 作为查询，跨视聚合辅视全序列的证据；多头结果拼接后经残差前馈得到 C_t。C_t 与 M_t 一一对齐（主视索引继承）。
    - 保留主视流 M_t 不改动，仅将 C_t 送入路由器。
  - 具身感知的分段状态编码与 token 级路由：
    - 将 37 维本体感觉分为 G=5 组（腿、臂手、头、腰、整体位姿），对每组 K 帧历史进行 LN、MLP 映射并加类型嵌入，得到各组表示；通过注意力加权与均值池化融合为共享具身条件 h_s。
    - 对每个索引 i 的 token，构造路由特征 q_{t,i} = [LN(M_{t,i}); LN(C_{t,i}); |差|; 点乘; h_s]，经轻量 MLP + Sigmoid 生成标量门 r_{t,i}，得到门控辅助 token eC_{t,i} = r_{t,i} * C_{t,i}。主视 M_t 不被缩放，仅参与路由描述。
  - VLA 集成与动作专家训练：
    - 将 [L_t; M_t; eC_t] 作为上下文，连同原始状态 S_t（注意：分段状态仅用于路由，不替换状态通道）送入 GR00T N1.7 动作专家，使用流匹配（flow matching）目标训练（Cosmos VLM 冻结）。
  - 部署细节（长时程控制与任务编排）：
    - 异步预测动作块并缓冲；块边界采用局部三次 B-spline 拼接，保证位置与速度连续，平滑过渡到新轨迹。
    - 外部 VLM 提供二值“子任务完成”信号，FSM 保持/切换当前指令，实现高层任务编排。
- 设计要点：
  - 主视保留：不替换预训练主视 token 路径，降低迁移风险，保持兼容性。
  - 跨视对齐：CVAT 以主视索引对齐，将辅视证据按主视空间关系组织。
  - 具身路由：依据身体分段的历史状态，动态选择何时、何处融合辅视证据，应对步态扰动与自遮挡。

## 6. 主要结论与发现
- 在真实类人长时程任务中，EATR-Stereo 取得：
  - 全任务成功 60.0%，抓取成功 100.0%，阶段成功 80.0%；ID/OOD 阶段成功 90.0%/70.0%，OOD 比 StereoPolicy 高 20 个百分点。
  - 语义遵循：左右指令 100%，颜色指令 80%。
- 严重不对称遮挡：
  - 恢复成功率 80%（CVAT-Flat 60%、CVAT 30%）；平均恢复时间 22.4s，快于 CVAT-Flat（41.7s）与 CVAT（>55s）。
- 仿真 RoboCasa365：
  - EATR-Stereo 总体成功率 43.33%，领先 CVAT、StereoPolicy、CVAT-Flat、QwenPI0.5、GR00T1.7、GR00T1.7-Mono。
- 核心方法学发现：
  - 保留主视 token 并以主视对齐的 CVAT 辅助流显著优于直接改写主视（Main-XAttn）。
  - 具身分段路由优于“平坦”路由；能在步态扰动、自遮挡时更有效选择辅视证据。
  - 在冻结 VLM 的前提下，以轻量接口达到与“显式深度+VLM微调”近似的阶段成功率，但训练时间显著更短。

## 7. 优点（方法与实验设计亮点）
- 表征与兼容性：

- 具身感知：
  - 身体分段的本体感觉历史作为条件，token 级门控路由精准控制何时融合辅视信息，适应动态自遮挡与视点变化。
- 训练与部署友好：
  - 冻结 VLM，轻量附加模块；训练成本比“显式深度+VLM微调”显著低。
  - 部署时异步动作块与局部 B-spline 拼接，保证长时程控制的轨迹连续与稳定。
- 评估设计扎实：
  - 实机长时程任务、ID/OOD泛化、遮挡恢复、多指标综合评估；仿真大规模补充验证。

## 8. 不足与局限（实验覆盖、偏差风险、应用限制）
- 平台与任务范围：
  - 真实评估集中在单一类人平台与单一长时程任务范式（瓶子抓取与放置）；尚需更多任务类型与更复杂交互验证。

  - 仿真排除腕部相机，虽有助于隔离双目因素，但与完整多传感器现实部署仍有差距。

- 泛化与适配：
  - 冻结 VLM 保证兼容但限制视觉表征自适应；对跨域、不同具身与多相机布局的泛化仍需系统评估。
- 方法边界：
  - 未显式建模不确定性与误差校准；未使用显式几何/深度，长期稳定的视差利用与遮挡推理可能受限。
- 数据与规模：
  - 真实训练示范为 1000 条，规模与多样性提升可能进一步优化泛化与鲁棒性。
