## 摘要
使用头戴式立体相机的长时程仿人视觉—语言—动作（VLA）控制需要一种视觉接口，既能利用互补视角，又能与预训练表征保持兼容。现有接口往往丢弃互补的立体证据，或在融合额外观测时未能保留原生的主视图通道，也未将辅助信息适配到机器人具身特性。我们提出 EATR-Stereo，这是一种具身感知的令牌路由框架，保留主视图令牌，并通过查询同步的辅视图令牌序列，构建与主视图对齐的跨视角辅助令牌（CVAT）。一个按身体分段的本体感受编码器进一步依据机器人的构型历史，对逐令牌的辅助使用进行调节，使得在动作生成过程中能够有选择地纳入立体证据。经路由的辅助流在保持其视觉—语言模型冻结的同时，增强了预训练 VLA 的语言与主视觉上下文。在一台具有 33 个自由度且本体感受状态为 37 维的实体仿人机器人上，我们在超过 100 秒的“搜索—接近—抓取—放置—返回”任务中评估了九种配置。EATR-Stereo 实现了 60.0% 的完整任务成功率、100.0% 的抓取成功率以及 80.0% 的阶段成功率。在严重的不对称遮挡条件下，与仅使用 CVAT 的 30% 相比，本方法将恢复率提高到 80%。消融研究进一步表明，保留主视图令牌以及将跨视角辅助特征与结构化本体感受路由相结合至关重要。这些结果表明，选择性路由的成对双目证据能够提升空间语义落地能力，从而实现可靠的长时程仿人 VLA 控制。

## Abstract
Long-horizon humanoid vision--language--action (VLA) control with head-mounted stereo cameras requires visual interfaces that can exploit complementary views while maintaining compatibility with pretrained representations. Existing interfaces often discard complementary stereo evidence or fuse additional observations without preserving the native primary-view pathway and adapting auxiliary information to robot embodiment. We present EATR-Stereo, an embodiment-aware token-routing framework that retains primary-view tokens and constructs primary-aligned Cross-View Auxiliary Tokens (CVATs) by querying the synchronized auxiliary-view token sequence. A body-segmented proprioceptive encoder further conditions token-wise auxiliary usage on robot configuration history, enabling selective incorporation of stereo evidence during action generation. The routed auxiliary stream augments the language and primary-visual context of a pretrained VLA while keeping its vision--language model frozen. On a 33-DoF physical humanoid with a 37-D proprioceptive state, we evaluate nine configurations in over-100-s search--approach--grasp--place--return tasks. EATR-Stereo achieves 60.0% full-task success, 100.0% grasp success, and 80.0% stage success. Under severe asymmetric occlusion, it improves recovery to 80% compared with 30% for CVAT alone. Ablation studies further show the importance of preserving primary tokens and combining cross-view auxiliary features with structured proprioceptive routing. These results demonstrate that selectively routed paired stereo evidence improves spatial grounding for reliable long-horizon humanoid VLA control.

- 问题背景
  - 仿人机器人在“头戴式双目相机 + 全身连续控制”的长时程 VLA 场景中，视觉感知强烈依赖具身状态（步态扰动、头腰转动、肢体自遮挡），阶段性视觉缺失会沿长任务传播，导致失败。
  - 双目（立体）相机的同步、固定基线与互补可见性有助于在遮挡、深度感知和跨视一致性下提升空间落地，但多数现有接口：
    - 仅使用单目或“拼接两帧图像”，未显式建模成对关系与时序对齐；
    - 或将双目融合为新表征，破坏了预训练 VLM 的原生“主视图”token 结构；
    - 融合视觉与本体感知时，缺乏根据具身状态选择性启用“辅视证据”的能力。
- 研究目标
  - 在不改动/微调预训练 VLM 的前提下，有效引入成对双目互补证据，同时保留主视图语义通路，并依据具身本体状态对来自辅视图的证据进行“逐 token 选择性路由”，以提升长时程仿人 VLA 控制的鲁棒性与空间落地。

## 2. 方法论：核心思想、关键技术与算法/流程
- 核心思想
  - 保留主视图 token（原生语义路径），从同步辅视图通过“主视查询—辅视键值”的跨视注意力，构造与主视索引一一对齐的“跨视辅助令牌”（CVAT）。
  - 用“按身体语义分段”的本体感知编码器（legs/arms/head/waist/pose，共5段）对近 K 帧状态历史建模，作为条件对每个主视对齐的 CVAT token 做“逐 token 门控路由”，决定是否、以及在多大强度上引入辅视证据。
  - 将“语言 + 主视 token + 路由后的 CVAT”一起喂给冻结的 VLM 上游后接的连续动作专家（flow matching），实现端到端动作块生成。
- 关键模块与细节
  1) 观测与输出
     - 观测 o_t = {I_L, I_R, 语言指令 ℓ_t, 本体历史 S_t=(s_{t−K+1: t})}；
     - 输出为长度 H 的连续动作块 Ŷ_t = (â_t,…,â_{t+H−1})。
  2) CVAT 构造（跨视注意，主视对齐）
     - 冻结的预训练 VLM（Cosmos-2B）分别编码主/辅视，得到 M_t（主）与 A_t（辅）；
     - 主视作 Query，辅视作 Key/Value，多头跨视注意得到 O_h，拼接+前馈残差得到 C_t；
     - C_t 与 M_t 一一对齐（每个主视 token 产生一个对齐的辅视辅助 token）。
  3) 具身感知分段编码与路由
     - 将本体状态按 legs/arms（含手）/head/waist/pose 五段，分别对 K 帧历史扁平化、LayerNorm、段内 MLP、加入段类型嵌入，得到 z_{t,g}；
     - 通过注意力加权 + 均值池化融合成共享条件 h_s_t；
     - 对每个 token i，构造路由描述 q_{t,i} = [LN(M_{t,i}); LN(C_{t,i}); |差值|; 逐元乘积; h_s_t]；
     - 轻量路由 MLP + Sigmoid 得到门控 r_{t,i}∈(0,1)，eC_{t,i} = r_{t,i}·C_{t,i}；
     - 注意：仅门控 CVAT；主视 token M_t 不改动，仅参与路由描述。
  4) VLA 集成与训练
     - 最终上下文拼接 E_VLA_t = [L_t; M_t; eC_t]，与原始状态 S_t 一起输入 GR00T N1.7 动作专家；
     - 采用流匹配目标 L_FM（在 chunk 内插时刻 τ，对速度场匹配），仅训练 CVAT 模块、分段状态编码器、路由器与动作专家，VLM 全程冻结。
  5) 推理与执行工程
     - 异步预测动作块入缓冲；块切换时用局部三次 B-spline 进行连续性拼接（保持边界位姿与速度连续并平滑过渡），每维独立拟合，使用 8 个采样路标与 8 个融合步；
     - 任务层面由外部 VLM 做子任务完成判别，有限状态机在完成后切换下一条指令（仅用于编排，不参与学习/融合）。
- 关键设计取舍
  - 保留“主视原生 token 通路”，避免破坏预训练 VLM 已学到的语义结构；
  - 仅将“对齐后的辅视证据”以附加流方式注入，并由具身状态决定其“使用位置与强度”（逐 token 路由）；
  - 不依赖相机内参/显式深度重建，利用同步与基线的隐式几何关联。
