## 摘要
视觉-语言-动作（VLA）模型在训练中出现的机器人任务上表现良好，但在未见过的场景和物体上难以泛化。其关键局限在于隐式的视觉表征，这种表征将物体外观、背景和场景布局纠缠在一起，使得策略对视觉变化非常敏感。已有研究通过结构化的中间表征来客体化视觉内容，从而改善可迁移性。然而，这些表征主要捕获了场景语义，而非与动作相关的关系，因此动作预测仍然依赖于外观统计。我们观察到，操作动作依赖于“物体–手–任务”的关系结构，该结构调控任务要求、机器人状态和物体属性之间的交互。基于这一观察，我们提出了 TriRelVLA：一种用于可泛化具身操作的三元关系 VLA 框架。我们的方法包括三个组件：（1）从多模态输入中构建显式的物体–手–任务三元表示，作为关系原语；（2）建立以任务为基础的关系图。由任务引导的跨注意力形成节点，关系感知图变换器用于建模节点间的交互；（3）执行基于关系条件的动作生成。将关系结构压缩进瓶颈空间并投射到大型语言模型（LLM）中进行动作预测。此三元关系瓶颈减少了对外观统计的依赖，支持跨场景、跨物体及跨任务组合的迁移。我们进一步引入一个用于微调的真实机器人数据集。实验结果显示，在微调任务上取得了强劲的性能，并在跨场景、跨物体和跨任务的泛化能力上有显著提升。

## Abstract
Vision-language-action (VLA) models perform well on training-seen robotic tasks but struggle to generalize to unseen scenes and objects. A key limitation lies in their implicit visual representations, which entangle object appearance, background, and scene layout. This makes policies sensitive to visual variations. Prior work improves transferability through structured intermediate representations that objectify visual content. However, these representations mainly capture scene semantics instead of action-relevant relations. As a result, action prediction remains tied to appearance statistics. We observe that manipulation actions depend on the object-hand-task relational structure, which governs interactions among task requirements, robot states, and object properties. Based on this observation, we propose TriRelVLA, a triadic relational VLA framework for generalizable embodied manipulation. Our approach consists of three components: 1) We construct explicit object-hand-task triadic representations from multimodal inputs as relational primitives. 2) We build a task-grounded relational graph. Task-guided cross-attention forms nodes, and a relation-aware graph transformer models interactions among them. 3) We perform relation-conditioned action generation. The relational structure is compressed into a bottleneck space and projected into the LLM for action prediction. This triadic relational bottleneck reduces reliance on appearance statistics and enables transfer across scenes, objects, and task compositions. We further introduce a real-world robotic dataset for fine-tuning. Experiments show strong performance on fine-tuned tasks and clear gains in cross-scene, cross-object, and cross-task generalization.

## 2. 方法论：TriRelVLA 框架

### 2.1 总体理念
TriRelVLA 提出**三元关系结构（Triadic Relational Structure）**作为视觉与动作之间的中介层，将对象、手部与任务的特征以图结构建模，再经关系感知的 LLM（大型语言模型）进行动作预测。

### 2.2 框架组成（对应 Fig. 2）
模型分为三个阶段：

#### （1）对象–手–任务（Object–Hand–Task）三元表示构建
- 输入包括多视角图像、机器人本体感知（proprioception）与语言指令。
- 使用 **SigLIP** 提取语义特征，**VGGT** 提取几何特征，两者结合形成统一三维视觉潜表示 \( F_v \)。
- 从 \( F_v \) 提取三类 token：
  - **对象表示** \( Z_o \)：通过 learnable object queries 从视觉特征中聚合物体证据。
  - **手部表示** \( Z_h \)：以机器人姿态嵌入为查询项，从视觉特征聚合与手相关的区域。
  - **任务表示** \( Z_t \)：从语言特征分解为四个子 token（动作、角色、约束、阶段）。
- 三者构成三元结构原语：\[ \{Z_o, Z_h, Z_t\} \]

#### （2）任务驱动的关系图建模（Task-Grounded Relational Graph）
- 通过**任务引导的跨注意力（cross-attention）**机制，将任务语义注入对象与手部 token，形成节点 \( V \)。
- 构造四类边：
  - Task–Object、Task–Hand、Object–Hand、Object–Object。
- 各边编码相对位置、姿态、距离及可达性等几何与交互特征。
- 采用**关系感知图变换器（relation-aware Graph Transformer）**，将边的语义直接注入注意力计算：
  \[
  \alpha_{ij} = \text{Softmax}_j \left( \frac{q_i(k_j + r_{ij})^\top}{\sqrt{d}} \right),\quad
  \hat{v}_i = v_i + \sum_{j\in N(i)} \alpha_{ij}(v_j + r_{ij})
  \]
  得到强化后的关系节点 \( \hat{V} \)。

#### （3）基于关系条件的动作生成（Relation-Conditioned Action Generation）
- 使用**关系瓶颈（Relational Bottleneck）**将增强节点 \( \hat{V} \) 压缩为 \( K \) 个高权重关系 token：
  \[
  r_k = \sum_i \alpha_{k,i} \hat{v}_i, \quad R = [r_1, r_2, \ldots, r_K]
  \]
- MLP 将瓶颈表示投影至语言空间 \( X_r \)，与 LLM 的语言 token \( X_l \) 级联，最终通过动作头输出 \( \hat{a} \)。
- 辅助损失包括：
  - 动作监督 \( L_\text{act} = ||\hat{a}-a||_1 \)
  - 对象与手部注意约束 \( L_\text{obj}, L_\text{hand} \)
  - 总损失 \( L = L_\text{act} + \lambda_oL_\text{obj} + \lambda_hL_\text{hand} \)
