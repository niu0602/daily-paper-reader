## 摘要
在可携式演示接口上的移动模仿学习面临两个耦合的瓶颈：被移动污染的动作标签以及在持续移动的基座上由推理引起的执行延迟。最近的腕部安装接口降低了桌面数据采集的成本，但单一腕部视角无法捕捉到基座导航所需的全局上下文。增加躯干部安装摄像头会将人的行走动作与手部运动耦合。同时，生成式策略会引入数百毫秒的推理延迟，在此期间，基座会越过预测的航路点，导致在动作拼接时需要进行反向修正。本文提出了 Mobile UMI，一种无需硬件的演示框架，通过三个组件解决上述问题。首先，双摄像采集系统分别记录胸前视角的全局上下文和腕部视角的局部交互，无需机器人参与。其次，基于一次性的 ChArUco 空间锚点，将胸部和手部的视觉-惯性坐标统一；随后将手部位姿重新表达为相对于胸部的形式，从而提取出解耦的 SE(3) 操作与 SE(2) 基座轨迹。第三，异步的递推视界执行器在在线状态匹配中工作：每个生成的动作片段在执行前都会根据当前物理位姿重新校准，以丢弃过期的航路点。整个系统在四项长时程家务任务上进行了评估，每项任务进行了 100 次试验，平均成功率达到 83.8%。在与 ACT 和 Diffusion Policy 的对照实验中，仅使用胸部相对标签就消除了大部分性能差距；在线状态匹配则进一步弥补了剩余部分。结果表明，在所测试的移动模仿学习条件下，显式的运动学分解结合状态级的延迟对齐，在不改变底层策略类别架构的前提下，提供了有效的解决方案。

## Abstract
Mobile imitation learning on portable demonstration interfaces faces two coupled bottlenecks: locomotion-contaminated action labels and inference-induced execution latency on a continuously moving base. Recent wrist-mounted interfaces lower the cost of tabletop data collection, yet a single wrist view does not capture the global context required for base navigation. Adding a body-mounted camera entangles human walking with hand motion. Meanwhile, generative policies introduce hundreds of milliseconds of inference latency, during which the base advances past predicted waypoints, forcing backward corrections at action splices. This paper presents Mobile UMI, a hardware-free demonstration framework that addresses both gaps through three components. First, a dual-camera capture system records chest-centric global context and wrist-centric local interaction without any robot present. Second, a one-shot ChArUco-based spatial anchor unifies the chest and hand visual-inertial frames; the hand pose is then re-expressed relative to the chest to extract decoupled SE(3) manipulation and SE(2) base trajectories. Third, an asynchronous receding-horizon executor performs online state matching: each generated action chunk is realigned with the current physical pose so that expired waypoints are discarded before execution. The full system is evaluated on four long-horizon household tasks, achieving an average success rate of 83.8% over 100 trials per task. Controlled comparisons against ACT and Diffusion Policy show that the chest-relative label alone closes much of the gap; online state matching closes the remainder. These results indicate that, for mobile imitation learning under the tested conditions, explicit kinematic factorization combined with state-level latency alignment provides an effective solution without requiring architectural changes to the underlying policy class.

## 1. 核心问题与研究背景

- **研究动机**  
  移动机器人在家庭、服务场景中需要同时完成**基座导航**与**手臂操作**，二者在运动学层面强耦合，难以在现实中通过模仿学习（imitation learning）有效分离。
- **面临的双重瓶颈**  
  1. **动作标签污染问题**：人体演示时，行走动作会影响手部相对位姿，导致数据集中的标签混合了移动基座和操作臂运动。

- **研究目标**  
  构建一个**无机器人硬件依赖**的演示框架，实现移动模仿学习的数据采集、表征解耦与延迟补偿，从而保证移动基座与操作臂的协调控制稳定性。

## 2. 核心方法与技术路线

### 2.1 整体思路

Mobile UMI 提出一个“**三要素集成框架**”，通过感知、表征与执行三层解耦实现稳定的移动操作学习：

1. **双摄像采集系统**：  
   - 胸部摄像头捕捉全局导航上下文（对应基座动作 SE(2)）；  
   - 腕部摄像头记录近场交互（对应手臂 SE(3)）；  
   - 数据采集完全无需机器人硬件。

2. **空间锚定与运动学去耦**：  
   - 使用 **ChArUco 棋盘标定板**建立胸部与腕部视觉-惯性坐标系的统一参考；  
   - 通过视觉惯性里程计（VIO, OpenVINS）获取两传感器的同步位姿轨迹；  
   - 将手部位姿转换为胸部参考系下的相对位姿：  
     \[
     T_{C_c}^{C_h}(t) = \left(T_{W_c}^{C_c}(t)\right)^{-1} T_{W_c}^{C_h}(t)
     \]
     此变换去除行走带来的全局平移，使手部动作仅反映局部操作。

3. **异步递推视界执行器（Receding-Horizon Executor）**：  
   - 在测试阶段，以异步方式预测与执行动作序列（Tp=16，Ta=8），并进行**在线时空状态匹配**。  
   - 每次根据当前物理状态匹配到预测轨迹中最相近索引 \(i^*\)，丢弃过期点：  
     \[
     i^* = \arg\min_i [w_b d^2_{SE(2)} + w_t \|\hat{p_i}-p_{now}\|^2 + w_r d^2_{SO(3)} + w_g(\hat{g_i}-g_{now})^2]
     \]
   - 确保动作在推理延迟后仍然物理一致。

### 2.2 关键算法：跨视角条件扩散策略（Cross-View Conditional Diffusion Policy）

- **输入观测**：胸部与腕部两路RGB图像 + 当前与历史运动状态；
- **视觉编码器**：共享权重的ResNet-18；
- **主干网络**：1D Temporal U-Net，用于生成动作分布；
- **条件注入**：通过FiLM层将扩散步\(k\)的时间嵌入注入残差块；
- **加速采样**：使用DDIM训练，加速推理至亚100ms延迟；
- **输出动作向量**：11维（3维基座 + 7维手臂增量 + 1维夹爪角度）。

## 7. 优点亮点

- **硬件与学习分离**：完全**无需机器人硬件**即可采集高质量移动操作演示，大幅降低数据采集成本。  
- **显式运动学解耦**：在数据层面分离SE(2)基座运动与SE(3)操作臂动作，增强学习清晰性。  
- **时空对齐控制**：在线“状态匹配 + 延迟丢弃”机制优雅地解决生成模型固有的时延问题。  
- **多模态跨视角设计**：融合胸部和手部视角，实现“全局导航 + 局部操作”的统一学习。  
- **工程可复现性高**：详细给出硬件规格、同步率与开源视觉模块（OpenVINS），具可移植性。

## 8. 不足与局限

- **动态力耦合缺失**：运动学去耦无法表达人体整体施力或反作用力，难以应对负载较大的操作任务。  
- **任务多样性有限**：仅使用单一操作员、实验室环境，泛化至多环境仍需验证。  
- **底盘模型简化**：执行端仅限差速底盘，未来需考虑非完整运动或全向平台。  
- **数据视角限制**：胸前与腕部摄像头可能遮挡或光照变化，尚未探讨鲁棒性问题。  
- **算力规模小**：仅单卡GPU验证，大模型或跨任务泛化性能未被充分评估。
