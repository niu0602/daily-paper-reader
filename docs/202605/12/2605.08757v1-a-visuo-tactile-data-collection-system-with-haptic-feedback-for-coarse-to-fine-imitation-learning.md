## 摘要
我们提出了一种视觉-触觉数据采集系统，用于生成具有时间结构和丰富接触信息的示范，以支持模仿学习。传统系统往往使操作员与接触力脱离，这阻碍了细微力调节的示范。我们的系统引入了一种由操作员用手指驱动的直接驱动式夹爪，保留了自然的触觉反馈。集成的视觉传感器和定制的触觉阵列可捕获图像序列和接触几何信息。安装在手柄上的按钮使操作者能够在任务执行过程中实时标注任务的时间结构，标记任务关键区域。通过结合手中力感知与原位时间标注，该系统可生成针对粗到细学习算法的多模态数据集，这些算法利用任务结构知识，从而实现高质量的操作策略开发。

## Abstract
We present a visuo-tactile data-collection system that generates temporally structured, contact-rich demonstrations for imitation learning. Conventional systems often decouple the operator from contact forces, which hinders the demonstration of subtle force modulation. Our system introduces a direct-drive gripper that the operator actuates with the fingers, preserving natural haptic feedback. Integrated visual sensors and custom tactile arrays capture image streams and contact geometry. A handle-mounted push button enables the operator to annotate the task's temporal structure in real time by marking task-critical regions. By fusing in-hand force perception with in-situ temporal annotation, the system produces multimodal datasets designed for coarse-to-fine learning algorithms that exploit structural task knowledge, enabling the development of high-quality manipulation policies.

## 一、研究背景与核心问题

- **研究动机**：模仿学习（Imitation Learning, IL）允许机器人通过人类示范直接学习复杂操控技能，尤其适用于接触丰富（contact-rich）的操作任务。然而，传统数据采集系统存在两大不足：
  1. **触觉反馈缺失**：多数接口仅记录运动信息（如位置、姿态），无法让操作者真实感受到接触力，妨碍了“细微力控制”示范的准确性。
  2. **任务结构标注缺乏**：当前系统通常无法在演示中动态标注任务阶段（如从“粗略接近”到“精细调整”），导致后续的“由粗到细（Coarse-to-Fine）”学习算法难以利用。

- **研究目标**：本文旨在建立一种**视觉-触觉一体化数据采集系统**，能：
  - 保留操作者的自然触觉反馈；
  - 捕捉多模态同步数据（视觉、触觉、运动状态）；
  - 实时标注任务关键阶段，从而生成结构化演示数据，支撑粗到细的模仿学习框架。

## 二、方法论与系统设计

### 2.1 核心思想
- 通过**直接驱动（Direct-drive）机械夹爪**实现自然触觉回馈；
- 将视觉、触觉与操作行为实时同步；
- 在操控时使用按钮进行任务阶段标注；
- 构建**时间对齐的多模态数据流**，供模仿学习算法训练。

### 2.2 系统组成与技术细节

| 模块 | 主要功能 | 技术实现 |
|------|------------|-----------|
| **夹爪（Gripper）** | 操作者直接用手指驱动两爪，从而感知真实接触阻力 | 自定义机械连杆系统，支持自然力调节 |
| **视觉传感器** | 捕获操作过程的第一人称影像 | GoPro 相机 + 鱼眼镜头，保证宽视野与部分遮挡鲁棒性 |
| **触觉传感器** | 获取接触几何与法向力分布 | 定制 3D-ViTac 传感阵列，每个传感垫为 16×16 压阻单元，可重建接触表面形貌 |
| **标注接口** | 实时标记任务关键阶段，如 coarse/fine | 手柄侧按钮，信号由 Arduino 微控制器读取并打时间戳 |
| **同步与数据处理** | 整合多模态数据流 | 利用 ORB-SLAM3 计算 6-DoF 位姿 + ArUco 标记追踪夹爪开合宽度 + 统一时间同步模块 |

### 2.3 数据生成流程
1. 同步采集视觉、触觉、标注信号；
2. 后处理：利用 ORB-SLAM3 估计 6-DoF 轨迹；
3. 整合所有模态（图像、触觉阵列、姿态、夹爪宽度、标注信号）；
4. 输出时间索引化、多模态演示序列，含任务分区标签（coarse/fine）。
