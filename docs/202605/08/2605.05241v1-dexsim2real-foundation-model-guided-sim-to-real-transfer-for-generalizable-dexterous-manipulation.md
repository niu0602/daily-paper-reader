## 摘要
从仿真到现实的迁移仍然是将仿真中学习的灵巧操作策略应用于现实机器人时的关键瓶颈。现有方法依赖人工设计的域随机化或任务特定的适应，这限制了它们在多样化操作场景中的泛化能力。我们提出 DexSim2Real，这是一种综合框架，利用视觉-语言基础模型来弥合灵巧操作中的仿真到现实差距。我们的系统结合了三个组件：（1）基础模型引导的域随机化（FM-DR），使用视觉-语言模型作为视觉真实感评估者，通过闭环 CMA-ES 优化仿真参数，并通过直接视觉反馈补充 DrEureka 等基于文本的方法；（2）一种触觉-视觉交叉注意力策略（TVCAP），将交叉注意力的视觉-触觉融合应用于零样本仿真到现实强化学习；（3）一种渐进技能课程（PSC），基于大语言模型的任务分解，并通过针对接触密集的灵巧任务定制的难度调度器进行增强。在六个具有挑战性的操作任务上进行了大量实验，在盲评条件下表明，DexSim2Real 实现了平均 78.2% 的现实世界成功率，优于 DrEureka 和 DeXtreme，并将仿真到现实的性能差距减少到仅 8.3%。

## Abstract
Sim-to-real transfer remains a critical bottleneck for deploying dexterous manipulation policies learned in simulation to real-world robots. Existing approaches rely on manually designed domain randomization or task-specific adaptation, limiting their generalizability across diverse manipulation scenarios. We present DexSim2Real, an integrated framework that leverages vision-language foundation models to bridge the sim-to-real gap for dexterous manipulation. Our system combines three components: (1) Foundation Model-Guided Domain Randomization (FM-DR), which uses a vision-language model as a visual realism critic to optimize simulation parameters via closed-loop CMA-ES, complementing text-based approaches like DrEureka with direct visual feedback; (2) a Tactile-Visual Cross-Attention Policy (TVCAP) that adapts cross-attention visuo-tactile fusion to zero-shot sim-to-real RL; and (3) a Progressive Skill Curriculum (PSC) that builds on LLM-based task decomposition with a difficulty scheduler tailored to contact-rich dexterous tasks. Extensive experiments on six challenging manipulation tasks with blinded evaluation demonstrate that DexSim2Real achieves a 78.2% average real-world success rate, outperforming DrEureka and DeXtreme while reducing the sim-to-real performance gap to only 8.3%.

**目标：**

## 二、方法论：DexSim2Real 框架

DexSim2Real 系统由三个核心模块构成。

### 1. 基础模型引导的域随机化（FM-DR）
- **核心思想：** 用视觉语言模型（VLM）作为“视觉真实感评估者（visual realism critic）”，闭环优化仿真环境参数。  
- **优化机制：**  
  - 将仿真参数（光照、纹理、摩擦、质量、相机姿态等）记为 $\xi = \{\xi_1, …, \xi_K\}$。  
  - 使用 GPT-4V 对比仿真渲染图与真实图，输出视觉真实评分 $s(\xi)$。  
  - 通过 **CMA-ES（协方差矩阵自适应演化策略）**优化参数分布：
    \[
    \theta^* = \arg \max_\theta E_{\xi \sim p(\cdot; \theta)} [s(\xi) + \lambda H(p(\cdot;\theta))]
    \]
    其中 \(H\) 表示分布熵，λ 控制多样性与真实度的权衡。  
- **迭代过程：** 每轮采样若干配置 → 渲染 → 评分 → 更新分布，约需 200–300 次 VLM 查询。

### 2. 触觉视觉交叉注意力策略（Tactile-Visual Cross-Attention Policy, TVCAP）
- **输入：** RGB 图像 + 多指触觉传感数据 + 机械臂本体状态。  
- **结构：** 三路编码器（ViT视觉、1D-CNN触觉、MLP本体）→ 双向交叉注意力融合 → Transformer 解码器输出动作序列。  
- **训练：** 使用 **PPO 强化学习算法**，按时间序列优化未来动作预测，目标函数包含剪切概率比项以稳定训练。

### 3. 渐进技能课程（Progressive Skill Curriculum, PSC）
- **思想：** 利用 LLM 自动分解复杂任务为多个子技能，按成功率动态调整训练难度 δ。  
- **调度公式：**  
  当子技能成功率 SR ≥ 0.8 时提升难度：
  \[
  \delta_{l}^{(t+1)} = \min(1, \delta_{l}^{(t)} + \alpha)
  \]
  （α=0.1为步长）  
- **技能链式学习：** 多个子技能达标后按状态衔接进行联合精炼。

## 八、不足与局限

- **触觉领域未优化**：当前FM-DR仅对视觉参数做优化，触觉信号仍依赖噪声随机化。  
- **计算成本偏高**：VLM查询虽较少，但仍存在实时应用障碍。  
- **对象类型限制**：仅验证刚体操作，未涵盖软体或流体任务。  
- **基础模型偏差**：视觉语义评分依赖VLM训练数据，可能引入偏见。  
- **未来方向**：加入触觉感知的FM-DR、降低VLM调用成本、扩展至双手及多任务场景。
